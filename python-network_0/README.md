# Python - Network #0

Bash scripts that use `curl` to inspect and interact with a web server.

| File | Description |
| --- | --- |
| 0-body_size.sh | Size of the response body in bytes |
| 1-body.sh | Body of a GET request (200 responses only) |
| 2-delete.sh | Sends a DELETE request and shows the body |
| 3-methods.sh | Lists the HTTP methods the server accepts |
| 4-header.sh | GET with header `X-HolbertonSchool-User-Id: 98` |
| 5-post_params.sh | POST with `email` and `subject` variables |
