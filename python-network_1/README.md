# Python - Network #1

Python scripts using `urllib` and `requests` to fetch URLs, read headers,
send POST requests, handle HTTP errors, and call JSON APIs.

| File | Description |
| --- | --- |
| 0-hbtn_status.py | Fetches a status URL with `urllib` |
| 1-hbtn_header.py | Prints `X-Request-Id` (`urllib`) |
| 2-post_email.py | POSTs an email (`urllib`) |
| 3-error_code.py | Handles `HTTPError` (`urllib`) |
| 4-hbtn_status.py | Fetches a status URL with `requests` |
| 5-hbtn_header.py | Prints `X-Request-Id` (`requests`) |
| 6-post_email.py | POSTs an email (`requests`) |
| 7-error_code.py | Prints error code if status >= 400 |
| 8-json_api.py | Search API with a letter, JSON handling |
| 10-my_github.py | Displays GitHub user id via Basic Auth |
