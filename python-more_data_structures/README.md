# Python - More Data Structures: Set, Dictionary

This project explores list comprehensions, sets, and dictionaries in Python 3.

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`
- Interpreted/compiled on Ubuntu 20.04 LTS using `python3` (version 3.8.5)
- All files end with a new line
- The first line of every file is exactly `#!/usr/bin/python3`
- Code follows the `pycodestyle` style (version 2.7.*)
- All files are executable
- No modules are imported

## Files

| File | Description |
| ---- | ----------- |
| `0-square_matrix_simple.py` | Returns a new matrix with the square of each value of the input matrix. |
| `1-search_replace.py` | Returns a new list with all occurrences of an element replaced by another. |
| `2-uniq_add.py` | Adds all unique integers in a list (only once for each integer). |
| `3-common_elements.py` | Returns a set of common elements in two sets. |
| `4-only_diff_elements.py` | Returns a set of all elements present in only one set. |
| `5-number_keys.py` | Returns the number of keys in a dictionary. |
| `6-print_sorted_dictionary.py` | Prints a dictionary by ordered keys. |
