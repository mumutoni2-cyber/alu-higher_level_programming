The ``5-text_indentation`` module
=================================

Using ``text_indentation``
--------------------------

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Each of '.', '?' and ':' is followed by two new lines:

    >>> text_indentation("Hello. How are you? Fine: thanks.")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    Fine:
    <BLANKLINE>
    thanks.
    <BLANKLINE>

Spaces at the start of each line are removed:

    >>> text_indentation("   Hi.    There.")
    Hi.
    <BLANKLINE>
    There.
    <BLANKLINE>

Text without a delimiter is printed as is (no trailing new line):

    >>> text_indentation("Hello"); print("")
    Hello

Empty text prints nothing:

    >>> text_indentation("")

    >>> text_indentation(12)
