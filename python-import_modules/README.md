# Python - Import Modules

This folder contains exercises focused on Python modules and imports.

## Objectives

- Understand how Python modules work
- Learn how to import functions, variables, and classes from modules
- Practice using built-in and custom modules
- Explore the `import`, `from ... import ...`, and `__import__` mechanisms

## Project Structure

The exercises in this folder cover topics such as:

- Importing modules
- Importing specific names from modules
- Handling module aliases
- Using built-in modules
- Creating and using custom modules

## Typical Commands

```bash
python3 script.py
python3 -c "import module_name"
```

## Notes

Each task in this folder is designed to help build a strong understanding of Python's module system and how code can be organized across multiple files.
