# python-data_structures

Python scripts exploring lists and other data structures.
All files are interpreted with python3 (3.8.5) on Ubuntu 20.04 LTS and follow pycodestyle 2.7.*.

## Tasks

### 0. Print a list of integers
`0-print_list_integer.py` defines `print_list_integer(my_list=[])`, which prints
all integers of a list, one per line, using `str.format()` (no imports, no casting to string).
