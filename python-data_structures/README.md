# python-data_structures

Python scripts on lists and other data structures (`alu-higher_level_programming`).
Run with `python3` (3.8.5) on Ubuntu 20.04 LTS; code follows pycodestyle 2.7.*.

| File | Description |
| --- | --- |
| `0-print_list_integer.py` | Prints the integers of a list |
| `1-element_at.py` | Returns the element at an index, or `None` |
| `2-replace_in_list.py` | Replaces an element in place |
| `3-print_reversed_list_integer.py` | Prints the integers of a list in reverse |
| `4-new_in_list.py` | Returns a copy with an element replaced |
| `5-no_c.py` | Removes every `c` and `C` from a string |
| `6-print_matrix_integer.py` | Prints a matrix of integers |
